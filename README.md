## 10-Day College Internship

This project task was completed as part of a **10-day internship program conducted by my college**.

During the internship, we were introduced to **Machine Learning (ML), Deep Learning (DL), and Data Analysis**. We worked with Python libraries such as **NumPy, Pandas, and Matplotlib**, along with various Machine Learning algorithms and concepts.

On the **final day of the internship**, we were assigned individual tasks to apply what we had learned during the internship. My assigned task was to **compare K-Fold Cross-Validation accuracy using Gini and Entropy as splitting criteria in a Decision Tree Classifier**, using the **Breast Cancer Dataset**.

**Comparison**
Criterion	Reported Accuracy
Entropy:	0.9350 Mean Accuracy
Gini:	0.9420 Average Testing Accuracy

Based on the reported values, Gini achieved a higher average testing accuracy (0.9420) compared with the reported mean accuracy for Entropy (0.9350).
